# The Crypto Trader Who Shocked the Internet: Kimchi

A 60 s vertical documentary-style short (1080x1920, 30 fps), delivered as six exact 10 s clips that join seamlessly.
Everything is generated by code: 3D scenes (three.js in Remotion, shared kit from `banks60`), AI narration (Kokoro
`am_puck`), captions with yellow keywords, and a synthesized score (suspense, then inspirational) plus sound effects.

Kimchi is shown as an anonymous stylised character (dark hoodie, red beanie), not a likeness of a real person. The coin
appears only as the "$TRUMP" ticker, with no politician's image.

## Rebuild
`python narration/make_narration.py …` → `python audio/make_audio.py` → render with `render.mjs` (`"scale":1.5`) →
`python make_clips.py` (six clips + the full 60 s + SRTs).
