# What if you invested $20 a month in Bitcoin?

A 60 s vertical (720x1280, 30 fps) 3D animated explainer, delivered as three 20 s clips. Everything is generated by code:
the 3D scenes (three.js in Remotion), the AI narration (Kokoro TTS, offline), and the music and sound effects (synthesized
in Python). No stock footage, no samples, no paid services.

## The numbers
| | |
|---|---|
| Purchases | $20 on the 1st of every month, July 2010 to November 2026 = **197 purchases, $3,940** |
| Bitcoin accumulated | **≈1,345–1,625 BTC** (depends on the 2010 price source, see below) |
| Value on Nov 13, 2026 | **≈$92–116 million** |
| Profit | **≈$92–116 million** (value minus $3,940) |

How it was calculated (`data/`):
- **Prices:** `habrador.csv` is a daily BTC-USD series (CoinDesk, later Yahoo/Investing.com) from
  [Habrador/Bitcoin-price-visualization](https://github.com/Habrador/Bitcoin-price-visualization) (2010-07-18 to
  2026-09-15). `bc_market.json` is blockchain.info's daily average market price (2010-08-18 to 2026-11-13).
- **Purchases:** `purchases.csv` lists every purchase with its price, BTC bought and running total. It uses Habrador
  prices, plus blockchain.info for Oct and Nov 2026, which Habrador doesn't cover.
- **July 2010:** no exchange price exists on July 1, 2010 (Mt.Gox opened on July 17), so the July purchase uses the first
  exchange price, July 18 ($0.09).
- **Valuation:** Coinbase BTC-USD for 2026-11-13, $68,765.99. blockchain.info's daily average for that day is $71,365.77.

Why a range and not one number: about 75% of the result comes from the first four purchases (Jul–Oct 2010, at
$0.06–0.09). Both reachable sources round those prices to the cent and disagree on July and August 2010:
- Habrador prices with the Coinbase valuation give 1,624.82 BTC = **$111.7M**.
- blockchain.info prices (no July 2010 price; the first price is Aug 18 at $0.07) give 1,344.73 BTC = **$92.5M**.
- Habrador BTC at blockchain.info's Nov 13 average gives **$116.0M**.
- From September 2010 onward the two sources agree within 1%.

To pin down one exact figure, recompute with tick-level Mt.Gox trade data for July–October 2010 (bitcoincharts.com's
mtgoxUSD archive, which was offline when this was made). Then put the result in `src/data.json` `range` and the
narration line 8, and re-render clip 3.

The crash figures are also computed from the daily series, close to close: -84% (Dec 16, 2017 → Dec 16, 2018) and -77%
(Nov 9, 2021 → Nov 21, 2022).

## Rebuild everything
```bash
npm install
python data/make_data.py                                  # src/data.json from the price files
python narration/make_narration.py kokoro-v1.0.onnx voices-v1.0.bin   # pip install kokoro-onnx soundfile scipy
python audio/make_audio.py                                # audio/mix.wav (music + sfx + voice, -14 LUFS)
node render.mjs '{"mode":"render","comp":"Bitcoin20","gl":"swangle","chromeMode":"headless-shell","scale":1,"from":0,"to":1799,"chunk":60,"out":"out/chunks","concurrency":1,"crf":17}'
python make_clips.py                                      # out/clip1.mp4, clip2.mp4, clip3.mp4
```
Kokoro model files: `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the
[kokoro-onnx releases](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0) (Apache-2.0). The
voice is `am_michael`. Rendering takes about 0.8 s per frame on CPU (software GL), about 25 minutes for all 60 s.
On a machine with a GPU, use `"gl":"angle"`.

## Files
| Path | What it is |
|---|---|
| `src/timeline.ts` | Scene timing, palette, data access, easing |
| `src/Scenes.tsx` | The 10 scenes and their camera moves |
| `src/Actors.tsx` | The investor character, crowd variants, coins, $20 bill |
| `src/textures.ts` | Painted textures: coin face, bill, 2010 screen, calendar, newspapers, crash screens |
| `src/Overlay.tsx` | On-screen text, counters, transitions, closing card and source note |
| `src/Video.tsx` | Composition: fonts, environment lighting, bloom, tone mapping |
| `narration/` | TTS script with each line's time window; `lines.json` timings |
| `audio/` | Synthesized score and SFX, ducking and loudness |
| `public/fonts/` | Anton and Inter (SIL Open Font License) |
